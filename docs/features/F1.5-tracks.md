# F1.5 Tracks

Status: draft

## User story

As an operator, I see where moving stations have been: a line behind each one through its recent positions, so a
vehicle's route, a balloon's drift or a hiker's path is clear at a glance. The station I'm following stands out, and
for the station I select I can see each point where it actually transmitted.

## Behavior

### History

1. The engine keeps a **position history** for each station, object and item in the store (F1.3): up to the last
   **500** positions, and none older than **2 hours** (both settings, Settings › Map › Tracks, per station like the
   store's times). A history is removed with its entry.
2. A position is added only when it **moves**: a report within 20 m of the previous point updates that point's time
   instead (a parked car beaconing every minute makes one point, not sixty). Ambiguous positions (F1.3) aren't added.
3. A point that implies an **impossible speed** (over 1,000 km/h from the previous point, except for a station whose
   symbol is an aircraft or balloon, over 3,000 km/h) is kept in the store as the latest position but not joined to the
   track, so a bad fix doesn't draw a line across the map. APRS.NET's track anomaly analysis (G24) decides this; until
   it ships, every point is joined.
4. Duplicates (F1.3 behavior 11, G05) never add points.

### On the map

5. A station with two or more points shows a **track**: a line through its points, oldest first, drawn under symbols
   and labels. Stationary stations draw nothing.
6. **Three styles**, from theme tokens (F0.6):
   - **Other stations**: thin, in the palette's track colour at reduced opacity;
   - **Selected** (F1.4 behavior 18): full opacity, with a small dot at each transmitted point;
   - **Followed** (F1.7): thicker, in the accent colour.
7. Track lines fade with their station (F1.4 behavior 19), and the oldest segments are drawn fainter than the newest,
   so direction is visible without arrows.
8. **Tracks** (Settings › Map, and the map layer toggle): All · Selected and followed only · None. Default: All.
9. Drawing stays within F1.4's frame budget with 2,000 stations and 50,000 track points shown: points are simplified
   per zoom level before drawing (points closer than a pixel are merged).

### Clearing

10. **Clear track** in the station's details (F1.6) empties that station's history except its latest point. Clearing
    all tracks is part of F1.19's Clear menu. On a gateway both are operator-only, because the history is shared.

## Service surface

- `StationDetail` (F1.3) gains nothing; a new `Task<IReadOnlyList<TrackPoint>> GetTrackAsync(string name)` returns a
  station's history (`TrackPoint`: latitude, longitude, time).
- The map stream gains track changes: `WatchTracksAsync()` streams, in the same coalesced batches as stations (F0.2),
  points appended per station and histories cleared or removed. A viewer that connects late gets a snapshot first.
- `ClearTrackAsync(string name)`, gated like settings on a gateway.
- Engine options: `TrackMaxPoints` (500), `TrackMaxAge` (2 h); the two become station settings in `AppSettings`.

## APRS.NET dependencies

- **G08, geodesy**: distance between points (behavior 2, the 20 m rule): delivered (`0.2.0-alpha.2`,
  `Geodesy.DistanceKm`).
- **G05**: duplicates (behavior 4): delivered (`0.2.0-alpha.2`, `DuplicateFilter`).
- **G24, track anomalies**: impossible speed (behavior 3), with the limits passed in as options.

## Desktop vs web differences

None: tracks are the engine's, and every viewer of a gateway sees the same. The display choice (behavior 8) is per
viewer.

## Acceptance tests

1. With a fake clock: moving positions build a history; one within 20 m updates the last point's time; 501 points keep
   500; points older than 2 hours drop.
2. A jump at 5,000 km/h isn't joined to the track; a balloon symbol at 2,000 km/h is.
3. The map draws the three styles from tokens in every palette; Tracks: None draws nothing.
4. A late viewer gets the snapshot, then appended points; Clear track empties one station and streams that.
5. Performance: 2,000 stations with 25 points each hold the frame budget (benchmark from spike 1, by hand).

## Decisions for review

1. **History limits**: 500 points and 2 hours (proposed), matching the store's removal time, so a track never outlives
   its station.
2. **Impossible-speed limits**: 1,000 km/h, or 3,000 km/h for aircraft and balloons (proposed).
