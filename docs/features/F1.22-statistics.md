# F1.22 Statistics

Status: draft

## User story

As an operator, I can see what is on the air around me in numbers: which devices and programs stations use, which
symbols are common, how many are heard on RF or only on APRS-IS, so I can understand my area and spot what's unusual.

## Behavior

1. A **Statistics** page (a shell destination, UX doc) with tables over the stations currently in the store (F1.3):
   1. **Platforms**: device vendor and model (G07), grouped by class (tracker, rig, software, digipeater, other), with
      counts and percentages;
   2. **Symbols**: each symbol with its drawing, name, count and percentage;
   3. **Kinds**: stations, objects, items;
   4. **Reception** (G20): RF direct, RF via digipeaters, APRS-IS only.
2. Tables sort by any column and are accessible tables (headers, row and column names for screen readers); each has
   a compact bar for the percentage, drawn from theme tokens with the number always written.
3. **Clicking a row** applies it as a view filter (F1.9) and opens the map, so "show me every APRSdroid station" is one
   click.
4. The page updates while open, at most every 5 seconds, and shows the time of its numbers.
5. **Copy** copies a table as tab-separated text, to paste into a spreadsheet.

## Service surface

- New `Task<StationStatistics> GetStatisticsAsync(StationFilter? filter)`: the tables, computed in the engine over
  the store (optionally within the viewer's filter). It shares the facet counts with F1.9's `GetViewFacetsAsync`.

## APRS.NET dependencies

- **G07, device identification**: until it ships, Platforms shows the raw TOCALL (destination) prefix groups instead.
- **G20**: until it ships, the Reception table isn't shown.

## Desktop vs web differences

None.

## Acceptance tests

1. From a scripted store, each table's counts and percentages are right and add up to the total.
2. Sorting, the accessible table names and the copy format are right; 200 % text in every palette.
3. Clicking a platform row sets the view filter and shows the map with only those stations.
4. Before G07, platforms group by TOCALL prefix.
