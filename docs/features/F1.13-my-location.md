# F1.13 My location

Status: building ([#71](https://github.com/APRS-NET/AprsMap/issues/71))

Built: the house at my location with the profile's callsign, never fading and not selectable, named in the map's hover
text; Set my location here from right-click, long-press or the context-menu key (the map's centre then), saved to the
active profile at once with Undo for 10 s, hidden on a read-only gateway (behaviors 1–3, 5, 6). Still to build:
distance and bearing (behavior 4).

## User story

As an operator, the app knows where my station is, so it can show me on the map, tell me how far and in which
direction every other station is, and centre the APRS-IS filter on me. I set it once, by typing it or by pointing at
the map, and change it when I move.

Built already: each profile has an optional location (F0.4), entered in the setup wizard and the profile editor by
locator, address, coordinates or this device (F0.5, F0.8); the stand-in filter and the map's opening view use it.

## Behavior

1. **My location is the active profile's location.** Each profile keeps its own (home, portable), and switching
   profile moves "me" with it. A live GPS position replaces it while GPS is on (F3.6, Phase 3).
2. **Set it on the map** (F1.4): right-click, or long-press on touch, offers **Set my location here**; the location is
   saved to the active profile at once, with **Undo** for 10 s. Typing it stays in the profile editor (F0.8).
3. **On the map**, my location shows as a house symbol (APRS `/-`) labelled with the profile's callsign, until my own
   station symbol exists (F2.1). It never fades or expires (F1.3).
4. **Distance and bearing from me** appear wherever a station is described: the details pane (F1.6), the station list
   with a sort by distance (F1.7), and the map's hover text (F1.4). Distance uses the viewer's distance unit (F0.4
   units); bearing is in whole degrees with a compass point (`NE 041°`). They are computed in the engine (G08), so the
   UI doesn't do geodesy.
5. Without a location, distance and bearing aren't shown (not "0 km"), and the map's **Home** button is hidden (F1.4).
6. **On a gateway** the location is the station's, like every profile setting: changing it from a browser needs the
   operator (F0.4's read-only gate). Each viewer still sees distances from the station's location.

## Service surface

- No new member for setting it: `SaveSettingsAsync` with the active profile's `Latitude`/`Longitude` (F0.4).
- `StationDetail` (F1.3) and the station list (F1.7) gain `DistanceKm` and `BearingDegrees` from the active profile's
  location, computed by the engine, null when either position is unknown.

## APRS.NET dependencies

- **G08, geodesy**: great-circle distance, initial bearing and compass point names: delivered (`0.2.0-alpha.2`,
  `Geodesy`; the Maidenhead part since `0.1.0-alpha.12`).

## Acceptance tests

1. Set my location here saves the active profile's location, with Undo; switching profile moves "me".
2. The house marker shows at my location with the callsign and never fades.
3. After G08: a station 100 km north-east shows `100 km NE 045°` (metric) or `62 mi NE 045°` (imperial); without my
   location nothing is shown.
4. On a read-only gateway the map's Set my location here is hidden.
