# Approved mockups

Source files for the UI mockups approved on 2026-10-13: 9 desktop screens and 6 web screens (browser plus phone width).
They are `.dc.html` design-canvas files and need the canvas runtime (`support.js`) to render, so view them on the
canvas: <https://claude.ai/artifact/L1RD2iWyhkEviPYchNh8FN> (private; ask the maintainer for access). `canvas.json` is
the layout of the canvas.

They show Light mode with the Standard palette only. The appearance options in [../README.md](../README.md#appearance-and-accessibility)
apply to every screen. Callsigns, coordinates and bracketed values are invented placeholders.

| File | Screen |
| --- | --- |
| `Main.dc.html` | Desktop main map |
| `DesktopTrack.dc.html` | Moving station selected, with track history |
| `DesktopHistory.dc.html` | Station history (weather station) |
| `DesktopMessages.dc.html` | Messaging |
| `DesktopFilters.dc.html` | Server filter and view filter settings |
| `DesktopBeacon.dc.html` | Beaconing settings |
| `DesktopPorts.dc.html` | Connections, with the Add connection dialog |
| `DesktopFirstRun.dc.html` | First-run wizard, location step |
| `DesktopObject.dc.html` | Create object from the map |
| `WebBrowser.dc.html` | Browser via the gateway, guest view |
| `PhoneMap.dc.html` | Phone: map |
| `PhoneTrack.dc.html` | Phone: station sheet with track |
| `PhoneMessages.dc.html` | Phone: chat |
| `PhoneFilters.dc.html` | Phone: filters |
| `PhoneSignIn.dc.html` | Phone: operator sign-in |
